# ATIN

## Tracking AI coding spend

This project is developed with the help of AI coding tools. To see where that spend actually goes (broken down by model, project, and task across 41+ AI tools including Claude Code), use [CodeBurn](https://github.com/getagentseal/codeburn) — a free, open-source, local-first usage tracker. It reads the session files your AI tools already write to disk; nothing leaves your machine.

```bash
npx codeburn
```

See the [CodeBurn README](https://github.com/getagentseal/codeburn) for the desktop app, web dashboard, and other installation options.
